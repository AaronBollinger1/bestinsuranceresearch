Birch bird favicon package

These canonical interface assets come from the approved
birch-final-favicon-package. The supplied bird is used unchanged in the
header, footer, loading state, favicon, app icons, and Commons property.

The full supplied logo is birch-bird-logo-transparent.png. The duplicate
birch-bird-transparent.png filename is retained as a compatibility path for
the shared interface components.

The page uses the supplied 32px PNG and ICO fallback. The app manifest uses the
supplied 192px and 512px PNGs. The PNG assets use transparent backgrounds.
